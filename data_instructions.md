# Data

No external data are used. Every sample is generated by simulating the system of Kiss et al. (2024),
Eqs. (9)-(10), with the parameters of Secs. 4.1-4.3 (all in `code/config.py`).
All randomness is seeded (`numpy.random.default_rng`):

| Use | Seeds |
|---|---|
| T1-T6 (seed-0 design) | 0 |
| T7 Monte Carlo and extension designs | 1-20 |
| H1 fmincon-like test | 0-9 |
| Extension sensor noise | seed + 5000 + 100*(noise level index) |
| Extension test multisines (never used for fitting) | 1001-1005 |
| Extension uniform test points in D_z | 777 |

The generated data that the report uses are stored in `results/` (JSON / NPZ / NPY).
