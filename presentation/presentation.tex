\begin{frame}{The problem and the paper's claim}
\begin{columns}[T]\begin{column}{0.55\textwidth}
\begin{itemize}
\item A nonlinear model is only reliable \alert{where the data are}.
\item Random-phase multisines keep the system near its operating point.
\item \textbf{Paper:} keep the amplitude spectrum, optimise only the 184 phases so that the samples
$z_k=[u_k,x_{1,k},x_{2,k}]$ fill a box $\mathcal D_z$.
\item \textbf{Claim:} cost $287.15\to3.88$ (``69$\times$''), better than Schroeder, robust over 20 starts.
\end{itemize}
\end{column}\begin{column}{0.42\textwidth}
\small Space-filling cost (Eq.~8):
\[ d_i=\sum_k e^{-\frac12\|\tilde z_i-z_k\|^2_{\Sigma^{-1}}},\qquad
C_\theta=\frac1n\sum_{i=1}^{8000}\frac{1}{\epsilon+d_i}\]
Empty grid point $\Rightarrow$ contributes $1/\epsilon$.
\end{column}\end{columns}
\end{frame}

\begin{frame}{Extension: does better coverage give a better model?}
\begin{itemize}
\item \textbf{Q1} Same spectrum, energy, length --- is the identified model more accurate?
\item \textbf{Q2} True system unknown: design on a model \alert{identified} from a first random-phase experiment
(surrogate), optionally re-identify and redesign (iterative).
\end{itemize}

\begin{frame}{Limitations}
\begin{itemize}
\item H1 supported, not proven: authors' optimiser options unknown.
\item $\epsilon$, steady-state rule, Schroeder index: my choices (fixed before results, M2).
\item Extension: one system, one model class, simulated sensor noise; noisy regressors give
errors-in-variables bias, smaller for designs that spread the states (noise-free case isolates coverage).
\item Surrogate design: 20 iterations; 100 iterations on a fixed surrogate helped little --- re-identify instead.
\item Converged optima differ across machines (round-off grows along the path): compare statistics, not single runs.
\end{itemize}
\end{frame}

\begin{frame}{Conclusion}
\begin{itemize}
\item The paper's method works: all qualitative findings and the early-stopped numbers are reproduced;
the converged optimum is even better than published.
\item The ``69$\times$'' is inconsistent with the paper's own numbers (74.0$\times$).
\item \textbf{Extension:} the coverage gain becomes a model-accuracy gain (\mFOfullforty$\times$, robust to a fixed
$\lambda$), and it survives designing by adjoint on an identified nonlinear model (\mFOiterforty$\times$).
\item Related: Kiss et al.\ (2026) report similar gains with a design on a linear model.
\end{itemize}
